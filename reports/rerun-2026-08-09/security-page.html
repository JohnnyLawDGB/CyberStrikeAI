Security at DigiScope

DigiScope works with DigiByte blockchain data, wallet interactions, and user accounts — so we treat security as a core part of the product, not an afterthought.

✓ Independent assessment · no critical or high-severity issues

Independent security assessment

In August 2026, DigiScope completed a comprehensive, authorized security assessment covering full reconnaissance, network and service scanning, TLS and cryptography analysis, web-application and API testing, and automated vulnerability scanning. The review found no critical or high-severity vulnerabilities in the DigiScope web application or API. Identified hardening opportunities are tracked and addressed through our ongoing security program.

How we protect DigiScope

  • Encryption everywhere. All traffic is served over modern TLS (1.2 / 1.3) with forward-secret, authenticated ciphers and HTTP Strict Transport Security. Legacy protocols are disabled.
  • Strong email authentication. Strict SPF and DMARC (reject) policies prevent email spoofing in our name.
  • Hardened infrastructure. Directory listing is disabled, sensitive files are not exposed, version banners are suppressed, and unnecessary services are kept closed.
  • Strict cross-origin policy. Our API enforces an allowlist CORS policy; untrusted origins are rejected.
  • Abuse protection. Global rate limiting guards our services against automated abuse.
  • Enforced authorization. Sensitive endpoints require authentication and enforce access controls before any action is taken.
  • Continuous review. We routinely scan and review our systems as new threats emerge.

Responsible disclosure

We welcome reports from security researchers. If you believe you've found a vulnerability, please email mark@aroundtheblock.us.

Please act in good faith: avoid privacy violations, service disruption, and data destruction, and give us reasonable time to remediate before any public disclosure. Machine-readable contact: /.well-known/security.txt.
